# 言語から外した機能のサンプル

`become` は 2026-08-22 に AIPL から外した。ここにあるのはその当時のサンプルで、
**現在の処理系では構文エラーになる**。

外した理由:

1. ABCL/1 には無い機構であった（ABCL/1 は状態変数と script の制約で表現していた）。
2. 型健全性の証明範囲 AIPL^-2 から元々外れていた。
3. 無制限だと、アクター型の区別を単独で無効にしていた
   （`actor(Closed)` と静的に見えているのに、become 後にそのメソッドが無い）。
4. 型を守るために「置換先は置換前が受け取れたメッセージをすべて受け取れること」を
   課すと、すべての状態がすべてのメッセージを受けることになり、
   状態フィールド＋分岐で書くのとほぼ同じになる。
5. 手元の .aipl **543 本を調べたところ、become を使っていたのはこの4本だけ**で、
   実アプリケーション（MANET・DOFBOT・Xinu・進化計算）では一つも使われていなかった。

置き換えの書き方は `docs/samples/paper/s08_state_machine.aipl` を見ること。
メッシュでの「役割の付け替え」は、become ではなく `deploy` による配備で表す。
